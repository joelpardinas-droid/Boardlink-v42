# Fonts

Liberation Sans (Regular, Bold, Italic) is used to write the compiled
comments PDF, so names and comments with ñ, curly quotes or the peso
sign (₱) print correctly.

Liberation Sans is © Red Hat, Inc., released under the SIL Open Font
License 1.1 (https://openfontlicense.org), which permits bundling it
with software.

Liberation Serif (Regular, Bold, Italic, Bold Italic) and Liberation Sans
Bold Italic are used for the documents made on the OCR page (the look of
Times New Roman, with bold, italic and both). Same licence.
